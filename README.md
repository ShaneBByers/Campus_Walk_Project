Campus Walk iOS Application

10/23/2016

This iOS application can be used by students and faculty of the large Penn State University campus. The application allows the user to navigate a map of the campus as well as pin known Penn State buildings on campus and create directions for the user to navigate from building to building.

This application is still in the early stages of development with some bugs that still need to be worked out as well as some UI/UX improvement required.

NOTES:

This is the third project completed for my Applications Programming course. With the transition from Swift 2 to Swift 3, as well as the incremental development process taken for this project, some bugs have arisen that seem to crash the app in certain cases.

All of the building names, locations, information, and pictures were provided to us by the professor for the course.

KNOWN ISSUES:

Whenever the user selects a favorite building, it does not appear to update the table view of all of the buildings as it should. After the user selects a favorite, it also seems to either crash or give the wrong building if the user tries to select a different building.

The favorite pin should differ more from the regular pin.

The UI for the directions on the map make no indication of what is the start and what is the end of the route.

Some simple UI/UX development needs to be completed for easier and more enjoyable use of the application.
